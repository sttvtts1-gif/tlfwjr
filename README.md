# GRAND SUN 실적 대시보드 (초안)

월간 실적발표용 웹 대시보드입니다. 단일 `index.html` 파일로 동작하며, 별도 빌드가 필요 없습니다.

## 구성 (발표 순서)
1. 표지 · 핵심 KPI
2. 월 실적 (전체/부산/경기, 전월대비, 달성율)
3. 유입 (직접/소개 – 용량·건수)
4. 계약타입 (발전사업/자가소비/임대/건물지원)
5. 개인별 월/누적 실적
6. 분기 실적
7. 2025·2026 월별 추이 및 예상
8. 익월 계약 가능건/확정건
9. 종합분석 및 개선방안

## 발표 모드
- `→ / ↓ / Space / PageDown` 다음 섹션, `← / ↑ / PageUp` 이전 섹션
- `F` 또는 우측 상단 **전체화면**
- **테마** 버튼으로 라이트/다크 전환

## 매월 업데이트 방법
`index.html` 상단의 `const DATA = { ... }` 블록만 수정하면 전체 화면이 갱신됩니다.
